HamTech M0FXB Yaesu FT-857D Controller - Windows x64
=====================================================

FOR NORMAL USERS
1. Extract ALL files from this ZIP to a normal folder.
2. Double-click HamTech-M0FXB-FT857D-Controller.exe.
3. Connect your FT-857D CAT interface and select the correct COM port/baud rate.

Radio setup:
- Menu 020 [CAT/LIN/TUN] = CAT
- Menu 019 [CAT RATE] = 4800, 9600 or 38400
- Controller baud rate must match the radio.
- CAT framing: 8 data bits, no parity, 2 stop bits.

This Release build is self-contained; users do not need the .NET SDK.
If Windows SmartScreen warns about an unsigned downloaded application, verify that
it came from the official HamTech M0FXB GitHub Release before choosing to run it.
